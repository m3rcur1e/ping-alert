# Ping Alert

Teammates' pings are hard to miss: a sound, a chat line with the coordinates, an arrow at the screen edge (clear of the HUD panels) and a card with a live view of the pinged place. Click the card to look there.

![Ping Alert](https://raw.githubusercontent.com/m3rcur1e/ping-alert/media/ping-alert.webp)

### Customizable

In **Settings › Ping Alert** (or **Cur1e Mods**):

- sound on/off
- chat line on/off
- arrow on/off
- cards on/off
- number of cards (1–3)
- card size
