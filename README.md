# Ping Alert

Teammates' pings are hard to miss: a sound, a chat line with the coordinates, an arrow at the screen edge and a card with a live view of the pinged place. Click the card to look there. Fully customizable.

![Ping Alert](https://raw.githubusercontent.com/m3rcur1e/ping-alert/media/ping-alert.webp)

**Settings › Ping Alert** (or **Cur1e Mods**): turn each part on or off, set the number and size of cards.
